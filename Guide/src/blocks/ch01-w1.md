:::worked Time to load one script
The bundle that runs the robot page of this website is about 686 kilobytes. A visitor is on a connection with 10 megabits per second of bandwidth and an 80 millisecond round-trip time. Estimate how long the file takes to arrive on a first visit.

**Step 1. Convert the size to bits.** 686 kilobytes is 686 000 bytes, and each byte is 8 bits, so the file is 686 000 × 8 = 5 488 000 bits, or 5.488 megabits.

**Step 2. Transfer time.** At 10 megabits per second, 5.488 megabits take 5.488 ÷ 10 = 0.549 seconds.

**Step 3. Connection set-up.** Assume three round trips before the request can be sent (name lookup, transport connection and encryption), and one more round trip for the request and the first byte of the reply. That is 4 × 0.080 = 0.320 seconds.

**Step 4. Total.** 0.549 + 0.320 = 0.869 seconds, to the nearest thousandth.

**What the answer tells you.** More than a third of the time is set-up, which no change to the file can remove. If the file were halved in size, the total would fall only to about 0.59 seconds. This is why a page that makes many small requests feels slower than one that makes a few larger ones, and why browsers keep connections open and reuse them. The estimate also ignores compression: servers usually compress text files with gzip or Brotli, which can reduce a script like this one to a third of its size.
