:::worked Smoothstep against linear
An element slides from x = 0 to x = 200 over one second. Compare its position at t = 0.25 and t = 0.5 using linear motion and smoothstep.

**Step 1. Linear.** Position = 200 t. At t = 0.25 it is 50, at t = 0.5 it is 100.

**Step 2. Smoothstep.** At t = 0.25: 3(0.0625) − 2(0.015625) = 0.1875 − 0.03125 = 0.15625, so the position is 200 × 0.15625 = 31.25. At t = 0.5: 3(0.25) − 2(0.125) = 0.75 − 0.25 = 0.5, so the position is 100.

**Step 3. Compare.** At t = 0.25 the eased element has covered only 31.25 of the 200 pixels, against 50 for the linear one: it is starting gently. At the midpoint they agree. By symmetry, the eased element is also behind at the end of its journey in the sense of slowing down: at t = 0.75 it is at 168.75, ahead of the linear 150, and it then settles into 200.

**Why it matters.** The two motions take the same time, but the eased one avoids the jolt at each end, and the eye reads it as more natural.
:::
