:::worked Which colour wins?
An element `<p id="note" class="warn small">` is matched by these four rules. Decide the colour of its text.

```
p              { color: black; }
.warn          { color: orange; }
p.warn.small   { color: red; }
#note          { color: blue; }
```

**Step 1. Score each selector.** `p` has one element selector: (0, 0, 1). `.warn` has one class: (0, 1, 0). `p.warn.small` has two classes and one element: (0, 2, 1). `#note` has one ID: (1, 0, 0).

**Step 2. Compare from the left.** The first number decides first. Only `#note` has a non-zero first number, so it outranks the other three whatever they contain.

**Step 3. Conclusion.** The text is blue. Notice that `p.warn.small` has more selectors than `#note` and still loses, because specificity is compared place by place and not added up.

**Moral.** Do not fight specificity by adding more selectors or by reaching for `!important`. Keep selectors flat (a single class where possible), and then order alone resolves most conflicts.
:::
