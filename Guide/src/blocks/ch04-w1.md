:::worked Sizing a canvas for a sharp chart
A chart canvas is displayed 430 CSS pixels wide and 300 CSS pixels tall on a laptop whose DPR is 2. What should the `width` and `height` attributes be? If the code draws a line from the point (100, 50) to (330, 50), where does it appear on the surface, and how thick is a line drawn with `lineWidth = 1`?

**Step 1. Surface size.** 430 × 2 = 860 and 300 × 2 = 600, so the drawing surface is 860 by 600 device pixels.

**Step 2. Transform.** The call `setTransform(2, 0, 0, 2, 0, 0)` multiplies every coordinate by 2. The point (100, 50) is therefore drawn at device pixel (200, 100), and (330, 50) at (660, 100).

**Step 3. Line thickness.** A `lineWidth` of 1 is 1 CSS pixel, which is 2 device pixels, so the line is two device pixels thick and crisp. On a DPR 1 screen the same code gives a one-pixel line with the same appearance, which is the point: one piece of code, sharp everywhere.

**Step 4. Cost.** The surface now holds 860 × 600 = 516 000 pixels instead of 129 000, four times as many. A page with many large canvases on a high-density phone can run short of memory or time, and this is why the robot page of this website caps the pixel ratio of its three-dimensional canvas (to 1.6 on a capable machine and to 1 on a weak one).
:::
