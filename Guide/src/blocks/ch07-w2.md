:::worked The brightness of a surface
A flat tabletop has the normal n = (0, 1, 0). A lamp lies in the direction l = (0.6, 0.8, 0) from the surface. Find the brightness, and the brightness if the lamp is moved to the direction (1, 1, 0) after normalising.

**Step 1. Check that l is a unit vector.** 0.6² + 0.8² = 0.36 + 0.64 = 1, so it is already unit length.

**Step 2. Dot product.** n · l = 0 × 0.6 + 1 × 0.8 + 0 × 0 = 0.8, so the brightness is 0.8.

**Step 3. The second lamp.** The vector (1, 1, 0) has length √2 = 1.4142, so the unit vector is (0.7071, 0.7071, 0). The dot product is 0.7071, so the brightness is 0.707.

**Step 4. Interpret.** A lamp directly overhead (l = (0, 1, 0)) would give the maximum of 1, and a lamp level with the surface would give 0. The tabletop looks dimmer as the lamp lowers, which is Lambert's law.
:::
