:::worked Predicting the order of output
What does this script print, and in what order?

```
console.log('A');
setTimeout(() => console.log('B'), 0);
Promise.resolve().then(() => console.log('C'));
console.log('D');
```

**Step 1. Run the script itself.** The script is one task. It executes from top to bottom without interruption. `console.log('A')` prints A at once.

**Step 2. Schedule the timer.** `setTimeout(..., 0)` does not run its callback now. It asks the browser to put the callback in the *task* queue as soon as possible, which is after the current task. So B is queued as a task.

**Step 3. Schedule the promise.** `Promise.resolve().then(...)` queues the callback as a *microtask*. So C is queued as a microtask.

**Step 4. Finish the script.** `console.log('D')` prints D. The task is now complete.

**Step 5. Drain the microtasks.** Before any new task, the loop runs all microtasks, so C prints.

**Step 6. Take the next task.** Only now does the loop run the timer's task, and B prints.

**Answer: A, D, C, B.** The timer's delay of zero does not mean "immediately". It means "after the current work and after all microtasks", and the surprise that C precedes B is the whole lesson.
