:::worked Evaluating a fluid heading
The heading above is set on a page whose root font size is 16 pixels. Find its size at viewport widths of 320, 700 and 1400 CSS pixels.

**Step 1. Convert the limits.** The minimum is 2.4 × 16 = 38.4 px, and the maximum is 4.2 × 16 = 67.2 px.

**Step 2. Evaluate the preferred value.** 6vw is 6% of the width: 19.2 px at 320, 42.0 px at 700, and 84.0 px at 1400.

**Step 3. Clamp.** At 320 the preferred value 19.2 is below the minimum, so the heading is 38.4 px. At 700 the value 42.0 lies between the limits, so the heading is 42.0 px. At 1400 the value 84.0 exceeds the maximum, so the heading is 67.2 px.

**Step 4. Interpret.** The heading grows with the screen only between viewport widths of 38.4 ÷ 0.06 = 640 px and 67.2 ÷ 0.06 = 1120 px, and is constant outside that range. Choosing the preferred value therefore chooses *where* the fluid range sits.
:::
